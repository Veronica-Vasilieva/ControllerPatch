# ControllerPatch — Asset attribution

The Xbox pad glyph textures and overview icon in `Assets/GlyphsHD/` and
`Assets/IconsHD/` were taken from the **Controller Forever** addon by
Controller Forever (`C:\Users\Jackb\Documents\ControllerForever`).

Controller Forever itself credits those glyphs to **ConsolePort** by
Sebastian Lindfors, distributed under the **Artistic License 2.0**. The
license text is included at `Assets/LICENSE-ConsolePort.md`.

- Original project (ConsolePort): https://github.com/seblindfors/ConsolePort
- Downstream project (Controller Forever): local source

No code was copied — Controller Forever targets retail WoW with native
gamepad support, which 3.3.5a does not have. The 3.3.5a backend for pad
input in this project is provided by `ControllerPatch.dll`.
